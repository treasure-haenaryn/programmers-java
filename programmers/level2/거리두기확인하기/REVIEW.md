# 거리두기 확인하기 — 코드 리뷰

- 문제: https://school.programmers.co.kr/learn/courses/30/lessons/81302 (Lv2, 2021 카카오 채용연계형 인턴십)
- 리뷰 날짜: 2026-10-08
- 리뷰 시점 결과: 예제 PASS, 하지만 채점에서 틀리는 버그 있음

## 잘한 점

- 각 P에서 O만 밟고 최대 2걸음까지 퍼져 보는 구조 (`depth == 2`에서 멈춤)
- X는 `continue`로 막고, 이웃이 P면 위반 처리
- `visited`에 출발 P를 먼저 표시해서 자기 자신을 "다른 P"로 세지 않음
- 대기실마다 `answer`를 따로 기록, `Arrays.fill(answer, 1)`로 기본값 설정

## 버그. 대기실의 한 줄만 검사함

```java
for (int i = 0; i < 5; i++) {            // i = 대기실 번호
    ...
    for (int j = 0; j < 5; j++) {
        if (map[i][j] == 'P') {          // 행 번호로 대기실 번호 i를 씀
            dfs(map, idx, new int[]{i, j}, ...);
```

`i`는 대기실 번호인데 행 번호로도 쓰고 있다. 그래서 대기실 0은 0행만, 대기실 1은 1행만 P를 찾는다.
나머지 4줄에 있는 P에서는 DFS가 시작되지 않는다.

예제는 위반 쌍이 우연히 검사하는 줄에 걸려서 통과했다.

반례: 5개 대기실 모두 4행에만 `PPOOO`(바로 옆 위반)

```
OOOOO
OOOOO
OOOOO
OOOOO
PPOOO
```

- 기대: `[0, 0, 0, 0, 0]`
- 결과: `[1, 1, 1, 1, 0]` (4행을 검사하는 대기실 4만 잡음)
- 랜덤 입력 2,000개(대기실 5개씩)를 단순 판정과 비교: 1,781개 불일치

## 수정

대기실 안의 모든 칸(행 `r`, 열 `c`)을 돌아야 한다.

```java
for (int r = 0; r < 5; r++) {
    for (int c = 0; c < 5; c++) {
        if (map[r][c] == 'P') {
            dfs(map, i, new int[]{r, c}, new boolean[5][5], 0);
        }
    }
}
```

검증: 반례 통과, 랜덤 입력 2,000개 모두 일치

## 핵심 정리: 판정 규칙

1. 거리(상하좌우 걸음 수)가 3 이상 → 무조건 OK
2. 거리 1 (바로 옆) → 무조건 위반
3. 거리 2 → 사이를 O로 지나갈 수 있으면 위반, 모든 길이 X로 막혀야 OK
   - 일직선 두 칸: 길 1개 / 대각선: 길 2개

구현: P의 상하좌우 → P면 위반, O면 그 O의 상하좌우(출발 P 제외)에 P가 있으면 위반

## 기억할 포인트

- 이중 반복에서 바깥 인덱스(대기실 번호)와 안쪽 인덱스(행·열)를 섞어 쓰지 않기. 인덱스마다 의미가 다른 이름(`room`, `r`, `c`)을 붙이면 실수가 줄어든다.
