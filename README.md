## 📚 배운 패턴 노트 (재사용 가능한 인사이트만)

문제별 세부 내용이 아니라, **여러 문제에 공통 적용되는 원칙**만 짧게 기록.

- BFS: visited 표시는 poll 시점이 아니라 offer(enqueue) 시점에 해야 큐가 안 불어남
- 벨만-포드: (n-1)번 완화로 최단거리 확정, n번째 반복에서도 갱신되면 음수 사이클
- 다익스트라: 음수 간선 불가하며 양수 간선만 가능, PQ에서 꺼낸 거리가 이미 기록된 최단거리보다 크면 continue 스킵
- 좌표 90도 회전 공식 : $(x, y) \rightarrow (y, -x)$
- 퍼즐 정규화(원점 이동 및 좌표 정렬): (minX, minY) 차감으로 원점 평행이동 후 좌표 정렬(X, Y 오름차순)해야 위치/탐색 순서와 무관하게 동일 모양 비교 가능
- 투포인터: 원소가 모두 양수여야 "합이 작으면 right++, 크면 left++"로 이동 방향을 정할 수 있음
- 투포인터/시뮬레이션 종료 조건: `4n` 같은 매직 넘버 대신 "무엇을 다 보면 끝나는가"로 정함 (예: 시작점이 한 바퀴 돌면 끝 → `left < 2n`)
- 원형 배열: 배열을 2배로 이어 붙이거나 `% n`으로 인덱스 감싸기. 시작 위치 `0 ~ n-1`, 길이 `1 ~ n`만 보면 중복/이중 합산 없음
- 매 단계 할 수 있는 행동이 하나로 정해지면 탐색(완전탐색/백트래킹)이 아니라 시뮬레이션
- 구간에 같은 값을 여러 번 더할 때: 차분 배열(시작 `+v`, 끝 다음 `-v`) 후 한 번에 누적합. 2차원은 네 꼭짓점 표시 후 행→열 누적합
- 그리디(최소 차이로 이기기): "상대 값보다 큰 것 중 가장 작은 값"은 `TreeMap.higherKey()`로 O(log n)
- 오버플로우: 원소 10^9 × 개수 10^5 이상이면 합은 `long`. `int + int`는 더하기 전에 한쪽을 `(long)`으로
- 경계값: `<` / `<=` 쓸 때 마지막으로 도는 값을 직접 대입해 확인 (예: `k < n-1`이면 n-1이 빠짐)
