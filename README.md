## 📚 배운 패턴 노트 (재사용 가능한 인사이트만)

문제별 세부 내용이 아니라, **여러 문제에 공통 적용되는 원칙**만 짧게 기록.

- BFS: visited 표시는 poll 시점이 아니라 offer(enqueue) 시점에 해야 큐가 안 불어남
- 벨만-포드: (n-1)번 완화로 최단거리 확정, n번째 반복에서도 갱신되면 음수 사이클
